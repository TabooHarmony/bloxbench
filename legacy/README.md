# Legacy Implementations

This directory contains rejected or superseded construction interventions kept only for historical reproduction.

- `SpatialHelpers.lua`: helpers v2 experiment
- `StructuralFixer.lua`: post-hoc repair experiment
- `experiments/`: old paired-run launchers

These files are not the active research path. The harness keeps explicit compatibility flags for reproducing them, but new experiments should use vanilla or `PartPrimitives.lua`.
