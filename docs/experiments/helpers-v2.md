# Helpers v2 Experiment

## verdict

rejected as the next intervention.

## evidence

Helpers v2 increased cost by roughly 60% versus vanilla and increased floating geometry on the reviewed building set. The helper abstraction did not solve the main decomposition problem and added prompt/tool overhead.

The implementation remains under `legacy/SpatialHelpers.lua` only for historical reproduction.
