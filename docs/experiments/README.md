# historical experiments

Every file in this directory is preserved research history, not current operating guidance.

- Do not launch a runner, revive an intervention, or copy a prompt from these reports for a new benchmark run.
- Older reports may mention `check_scene`, `check_game`, machine gates, judges, helpers, primitives, fixers, or relation arms. Those terms describe the historical run, not the current evaluation contract.
- The current contract is in `../ARCHITECTURE.md` and `../PROJECT_STATE.md`: one root `harness.py`, one chosen Studio control backend, screenshots for review, and human pairwise preference only.
- Historical result directories under `../../results_pull/` are evidence. They are not automatically promoted to a current baseline.

Before any new work, verify the live code and the active BloxBench skill rather than treating an experiment report or handoff as authority.
