# BloxBench

Construction benchmark for Roblox builds from text prompts.

The eval loop is: fixture prompt → model source generation (Charm Hyper, HYPER_API_KEY) → RSC/Studio execution → .rbxl place file + structured readbacks → human pairwise review in Studio (A better, B better, tie, both bad). Place file is the review surface; screenshots are diagnostic only. v1 benchmark is direct one-shot only — no external fixer, no agentic self-repair loop in the score.

HYPER_API_KEY: stored in project .env (gitignored, `HYPER_API_KEY=sk-hyper-...`). Also auto-loaded from there by `scripts/benchmark/generate_candidate.py:_load_hyper_key_from_dotenv()` so future sessions don't need it in the shell env. Do not paste it in Discord, do not write it to artifacts, do not switch providers without asking.
