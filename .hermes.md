# BloxBench agent context

## what this is

Construction benchmark. Fixtures in `Evals/` are the dataset. Subagents + RSC are the eval loop. Human pairwise review is the gate.

## what this is not

There is no python harness. The old harness was archived on 2026-07-30. Do not reference, import, or revive it. Do not build a replacement runner, wrapper, or model loop.

## rules

- A successful process, result JSON, part count, or `passed` flag is not visual evidence.
- Require real screenshots and results before calling a run reviewable.
- Run one canary before any batch. Keep the model, backend, Studio session, and fixture fixed while diagnosing.
- Do not change the model API, MCP backend, plugin, Studio launcher, and parser in one experiment.
- Do not expose credentials in prompts, handoffs, results, logs, or commits.
