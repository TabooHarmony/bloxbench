# BloxBench

Construction benchmark for Roblox builds from text prompts.

Fixtures in `Evals/` are the dataset: 32 Lua files across six tracks (Building, UI, Gameplay, Props, Scenes, VFX). Each defines a prompt, rubric, and metadata.

The eval loop is: fixture prompt → hermes subagent → rsc_submit/rsc_job → Studio → screenshots → human pairwise review (A better, B better, tie, both bad).
